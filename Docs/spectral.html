Laplacian Propagation

This page documents the current Laplacian pipeline: DINOv2 KNN rankings are converted into a weighted graph, then grouped through the normalized graph Laplacian.

Overview Data Flow Feature Extraction Graph Export Laplacian Propagation

Main script

propagando_rotulos.py reads the KNN ranking JSON, builds a weighted graph, computes the normalized Laplacian explicitly, and runs KMeans in Laplacian space.

Plot helpers

Aux.py contains the plotting functions used to save the cluster graph, correctness graph, and Laplacian scatter plot.

Evaluation only

The Flowers labels are used only after clustering to measure quality. They are not used to form the clusters.

python3 Code/Core/Laplaciano_Propagacao/propagando_rotulos.py --k 20

Pipeline

  1. Read nearest-neighbor rankings from DataSets/Runs/dinov2_vits14_output.json.
  2. Build the weighted KNN adjacency matrix W.
  3. Use rank weights: first neighbor gets 1.0, second gets 0.5, and rank r gets 1/r.
  4. Add W to W.T, producing an undirected weighted graph where reciprocal KNN relationships become stronger.
  5. Build a NetworkX graph from W for layout and JSON export.
  6. Compute the normalized graph Laplacian explicitly.
  7. Compute the smallest num_clusters eigenvectors of the Laplacian.
  8. Normalize each row of the eigenvector matrix.
  9. Run KMeans on the Laplacian embedding.
  10. Map arbitrary cluster IDs to true class IDs with the Hungarian algorithm for evaluation.
  11. Export arrays, graph JSON, and plots to DataSets/Laplacian.
Label assumption: the current script assumes the Oxford-17 ordering: 17 classes, 80 images per class, ordered by filename. This is controlled by --num-clusters and --samples-per-class.

Graph Construction

The ranking file contains rows like [0, 7, 20, 39, ...]. The first item is usually the node itself. For k=20, the script uses the next 20 entries as neighbors.

W = np.zeros((n_samples, n_samples), dtype=float)

for i in range(n_samples):
    neighbors = rankings[i, 1 : args.k + 1]
    for rank, j in enumerate(neighbors, start=1):
        if i == j:
            continue
        W[i, j] = max(W[i, j], 1.0 / rank)

W = W + W.T

The rank weight makes closer neighbors stronger. The final W + W.T step makes the graph undirected and rewards reciprocal neighbors by adding both directional weights.

Normalized Laplacian

The script computes the normalized graph Laplacian explicitly instead of hiding it inside a library call:

L = I - D^(-1/2) W D^(-1/2)
degrees = W.sum(axis=1)
d_inv_sqrt = np.zeros_like(degrees)
nonzero_degrees = degrees > 0
d_inv_sqrt[nonzero_degrees] = 1.0 / np.sqrt(degrees[nonzero_degrees])

normalized_adjacency = d_inv_sqrt[:, None] * W * d_inv_sqrt[None, :]
L = np.eye(n_samples) - normalized_adjacency

Here, D is the diagonal degree matrix and d_i = sum_j W[i, j]. The code avoids building the full diagonal matrix by multiplying rows and columns with 1 / sqrt(d_i).

Eigenvectors And KMeans

The smallest Laplacian eigenvectors produce the Laplacian embedding. Each image becomes one row in the eigenvector matrix. The rows are normalized, then KMeans converts the continuous Laplacian coordinates into discrete cluster IDs.

eigenvalues, U = eigsh(L, k=args.num_clusters, which="SM")
order = np.argsort(eigenvalues)
eigenvalues = eigenvalues[order]
U = U[:, order]

row_norms = np.linalg.norm(U, axis=1, keepdims=True)
row_norms[row_norms == 0] = 1.0
Y = U / row_norms

clusters = KMeans(
    n_clusters=args.num_clusters,
    n_init=50,
    random_state=args.seed,
).fit_predict(Y)

Evaluation

KMeans cluster IDs are arbitrary. Cluster 0 does not necessarily mean class 0. To compute accuracy, the script builds a cluster-vs-class confusion matrix and uses the Hungarian algorithm to find the best one-to-one cluster-to-class assignment.

rows, cols = linear_sum_assignment(confusion.max() - confusion)
cluster_to_class = {int(row): int(col) for row, col in zip(rows, cols)}
mapped_labels = np.array([cluster_to_class[c] for c in clusters])
MetricWhat it means
Accuracy after optimal mappingPercentage of samples whose mapped cluster label equals the true label.
Adjusted Rand IndexPairwise clustering agreement adjusted for chance. Good for evaluating partitions independent of cluster names.
Normalized Mutual InformationInformation shared between predicted clusters and true labels, normalized to make scores comparable.

Key Point

This code is unsupervised Laplacian propagation on a weighted KNN graph. Labels are not used to create clusters; they are used only afterward to evaluate how well the discovered clusters align with known Flowers classes.
