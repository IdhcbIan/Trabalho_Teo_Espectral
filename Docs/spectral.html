True Spectral Clustering

This page documents both spectral clustering implementations: the KNN-ranking graph version and the literal Ng-Jordan-Weiss cosine-affinity version.

KNN-Graph Pipeline

  1. Read nearest-neighbor rankings from DataSets/Runs/dinov2_vits14_output.json.
  2. Load or infer true labels for evaluation.
  3. Build a weighted KNN adjacency matrix W.
  4. Symmetrize W, producing an undirected weighted graph.
  5. Compute the normalized graph Laplacian.
  6. Compute the smallest num_clusters eigenvectors.
  7. Normalize each row of the eigenvector matrix.
  8. Run KMeans on the spectral embedding.
  9. Map cluster IDs to true class IDs with the Hungarian algorithm for evaluation.
  10. Export arrays, graph JSON, and visual plots.

Ng-Jordan-Weiss Pipeline

  1. Load Flowers embeddings from DataSets/Emb/Flowers_emb.pt.
  2. L2-normalize the embeddings.
  3. Build dense cosine affinity matrix A = X X^T.
  4. Clamp negative cosine similarities to zero and clear the diagonal.
  5. Compute L = D^(-1/2) A D^(-1/2).
  6. Take the largest eigenvectors of the normalized affinity matrix.
  7. Normalize each row of the eigenvector matrix.
  8. Run KMeans on the normalized rows.
  9. Evaluate clusters with Flowers labels using Hungarian cluster-to-class matching.
  10. Save arrays and the same three plots: cluster graph, correctness graph, and spectral scatter plot.

Graph Construction

The ranking file contains rows like [0, 7, 20, 39, ...]. The first item is usually the node itself. For k=20, the script uses the next 20 entries as neighbors.

The adjacency matrix is weighted by neighbor rank:

rank 1 neighbor  -> weight 1.0
rank 2 neighbor  -> weight 0.5
rank 3 neighbor  -> weight 0.333...
...
rank 20 neighbor -> weight 0.05

The graph is then symmetrized with max(W, W.T). If image A considers image B a close neighbor, the undirected graph keeps that relation even if B did not rank A the same way.

Function: spectral_embedding

def spectral_embedding(adjacency, num_clusters):
    laplacian = csgraph.laplacian(adjacency, normed=True)
    eigenvalues, eigenvectors = eigsh(laplacian, k=num_clusters, which="SM")
    ...
    embedding = eigenvectors / row_norms
    return eigenvalues, embedding

Normalized Laplacian

The normalized graph Laplacian is computed by SciPy with normed=True. Conceptually, it is:

L_norm = I - D^(-1/2) W D^(-1/2)

Here, W is the weighted adjacency matrix and D is the diagonal degree matrix. Normalization reduces the effect of nodes with very different degrees.

Smallest Eigenvectors

eigsh(..., which="SM") asks for the eigenvectors associated with the smallest eigenvalues. In spectral clustering, these eigenvectors reveal low-frequency graph structure: groups of nodes that are strongly connected internally and weakly connected externally.

Sorting

The eigenpairs are sorted by eigenvalue so the output is stable and interpretable:

order = np.argsort(eigenvalues)
eigenvalues = eigenvalues[order]
eigenvectors = eigenvectors[:, order]

Row Normalization

Each image is represented by one row in the eigenvector matrix. The script normalizes every row to unit length before KMeans:

row_norms = np.linalg.norm(eigenvectors, axis=1, keepdims=True)
embedding = eigenvectors / row_norms

This is the common Ng-Jordan-Weiss spectral clustering step. It makes KMeans focus on angular cluster structure in the spectral space instead of raw vector magnitude.

Function: run_kmeans

def run_kmeans(embedding, num_clusters, seed):
    kmeans = KMeans(n_clusters=num_clusters, n_init=50, random_state=seed)
    return kmeans.fit_predict(embedding)

KMeans receives the spectral embedding, not the original DINOv2 features. The parameter n_init=50 runs KMeans multiple times with different initial centroids and keeps the best result. This reduces sensitivity to initialization.

Function: map_clusters_to_labels

KMeans cluster IDs are arbitrary. Cluster 0 does not necessarily mean class 0. To compute accuracy, the script creates a confusion matrix and finds the best one-to-one cluster-to-label assignment.

rows, cols = linear_sum_assignment(confusion.max() - confusion)
mapping = {cluster_ids[row]: true_labels[col] for row, col in zip(rows, cols)}

linear_sum_assignment solves the Hungarian assignment problem. Since it minimizes cost, the code transforms counts into costs using confusion.max() - confusion. Larger overlap becomes smaller cost.

Evaluation Metrics

Main Function Walkthrough

  1. parse_args() reads CLI arguments.
  2. The output directory is created with mkdir(parents=True, exist_ok=True).
  3. load_rankings reads the KNN ranking file.
  4. load_labels provides labels for evaluation.
  5. build_knn_adjacency constructs W.
  6. spectral_embedding computes eigenvalues and row-normalized eigenvectors.
  7. run_kmeans returns cluster IDs.
  8. map_clusters_to_labels maps arbitrary cluster IDs to class IDs for accuracy.
  9. graph_from_adjacency builds a NetworkX graph.
  10. nx.spring_layout computes graph coordinates for visualization and JSON export.
  11. NumPy arrays are saved for later analysis.
  12. Graph JSON and plots are exported.
  13. print_metrics prints metrics and per-class scores.
