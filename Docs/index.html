Project documentation

DINOv2 embeddings, KNN graphs, and spectral clustering

This documentation explains the code in the project root, the generated dataset artifacts, and the graph-learning workflows.

Overview Data Flow Feature Extraction Graph Export Spectral Clustering

Core idea

Images are converted into DINOv2 feature vectors. A nearest-neighbor ranking builds a graph, and spectral clustering discovers communities from normalized Laplacian eigenvectors.

Current dataset

The Flowers dataset currently has 1360 images and the extracted embedding matrix has shape 1360 x 384.

Spectral clustering

The spectral script computes normalized Laplacian eigenvectors, clusters them with KMeans, and evaluates clusters after optimal label matching.

Repository Map

PathPurpose
Code/Core/ExtractData/Extract.pyMain extraction pipeline. Collects image paths, runs DINOv2, saves embeddings, computes KNN rankings, and exports graph JSON files.
Code/Core/ExtractData/DinoV2.pyLoads a DINOv2 model from Torch Hub and extracts image features in batches.
Code/Core/ExtractData/Graph.pyBuilds KNN NetworkX graphs from ranking arrays and exports graph positions plus edges.
Code/Core/SpectralClustering/spectral_clustering.pyComputes normalized Laplacian eigenvectors, clusters them with KMeans, and exports spectral clustering results.
Code/Core/SpectralClustering/Aux.pyContains plotting helpers for the spectral clustering script.
DataSets/Emb/Generated NumPy embedding arrays.
DataSets/Runs/Generated nearest-neighbor ranking JSON files.
DataSets/Plots/Generated KNN graph JSON files for visualization.
DataSets/Spectral/Generated spectral clusters, embeddings, graph JSON, and PNG plots.

Primary Commands

python3 Code/Core/ExtractData/Extract.py
python3 Code/Core/SpectralClustering/spectral_clustering.py --k 20
Label assumption: Flowers accuracy currently uses the standard Oxford-17 layout: 17 classes, 80 images per class, ordered by filename. Pass --labels path/to/labels.txt to use an explicit label file.
