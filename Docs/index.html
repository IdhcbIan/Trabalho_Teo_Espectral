Project documentation

DINOv2 embeddings, KNN graphs, and Laplacian propagation

This documentation explains the code in the project root, the generated dataset artifacts, and the graph-learning workflows.

Overview Data Flow Feature Extraction Graph Export Laplacian Propagation

Core idea

Images are converted into DINOv2 feature vectors. A nearest-neighbor ranking builds a graph, and Laplacian propagation groups images from normalized Laplacian eigenvectors.

Current dataset

The Flowers dataset currently has 1360 images and the extracted embedding matrix has shape 1360 x 384.

Laplacian propagation

The propagation script computes normalized Laplacian eigenvectors, clusters them with KMeans, and evaluates clusters after optimal label matching.

Repository Map
