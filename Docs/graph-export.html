KNN Graph Export

Graph.py converts ranking arrays into NetworkX graphs and JSON files that can be loaded by graph visualization tools.

Overview Data Flow Feature Extraction Graph Export Spectral Clustering

Main Functions

FunctionResponsibility
plot_and_export(rankings, k_list, model_name)Loops through each K value, builds a graph, computes positions, and exports JSON.
visualize_knn_graph(...)Creates a directed KNN graph, runs nx.spring_layout, optionally saves a Matplotlib figure, and returns graph plus positions.
export_graph_positions(G, pos, model_name, k)Writes node positions and outgoing neighbor lists into a JSON file.

Graph Construction

Every image becomes a graph node. For node i, the script adds directed edges from i to the first k ranked neighbors, skipping the first ranking entry because it is usually the node itself.

for i in range(len(rankings)):
    for j in range(1, min(k + 1, len(rankings[i]))):
        if i != rankings[i][j]:
            G.add_edge(i, rankings[i][j])

Export Format

{
  "nodes": {
    "0": {
      "position": [x, y],
      "attributes": {}
    }
  },
  "edges": {
    "0": [7, 20, 39]
  },
  "graph_info": {
    "num_nodes": 1360,
    "num_edges": 27196,
    "k": 20
  }
}
