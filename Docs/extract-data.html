Extract.py

Extract.py is the main script for producing embeddings, rankings, and KNN graph exports from the Flowers image directory.

Configuration

NameCurrent valueRole
dataset_nameFlowersSelects DataSets/Flowers/imgs and output embedding filename.
model_namedinov2_vits14Model name passed to torch.hub.load.
k_list[10, 20, 30, 40, 60, 80]K values used when exporting graph JSON files.

Important Steps

  1. Resolve project paths from Path(__file__).resolve(), so the script does not depend on the shell working directory.
  2. Load filenames with os.listdir and sort with natsort.natsorted.
  3. Keep only .jpg files and build full image paths.
  4. Call dinov2_inference(model_name, image_paths).
  5. Save embeddings to DataSets/Emb/Flowers_emb.npy.
  6. Build nearest-neighbor rankings with sklearn.neighbors.BallTree.
  7. Write rankings to DataSets/Runs/dinov2_vits14_output.json.
  8. Call plot_and_export to write graph JSON files under DataSets/Plots.

DinoV2.py

DinoV2.py contains the model inference function. It chooses CUDA when available, otherwise CPU.

Image Transform

Resize(256)
CenterCrop(224)
ToTensor()
Normalize(mean=[0.485, 0.456, 0.406],
          std=[0.229, 0.224, 0.225])

Batching

The batch size is max(1, len(image_paths) // 10). This prevents a zero batch size for small datasets and splits the dataset into roughly ten batches.

Output

The function returns a single NumPy matrix made by vertically stacking all batch outputs. For current Flowers data, the saved result has shape 1360 x 384.
