Pipeline

Data Flow

The project converts image files into embeddings, rankings, graph exports, and Laplacian propagation outputs.

Overview Data Flow Feature Extraction Graph Export Laplacian Propagation

End-to-End Flow

  1. DataSets/Flowers/imgs contains image files named image_0001.jpg through image_1360.jpg.
  2. Extract.py sorts the filenames naturally so numerical order is preserved.
  3. DinoV2.py preprocesses each image and returns a feature matrix.
  4. The feature matrix is saved as DataSets/Emb/Flowers_emb.npy.
  5. BallTree queries nearest neighbors for every image and exports rankings to DataSets/Runs/dinov2_vits14_output.json.
  6. Graph.py converts those rankings into KNN graph JSON files in DataSets/Plots.
  7. propagando_rotulos.py reads the ranking JSON, builds a weighted KNN adjacency matrix, computes normalized Laplacian eigenvectors, and runs KMeans in Laplacian space.
  8. Laplacian propagation outputs are written to DataSets/Laplacian.
